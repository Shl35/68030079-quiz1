# การควบคุม LED 8 ดวงด้วย ESP32 และสวิตช์ 2 ตัว (ESP-IDF - ข้อสอบข้อที่ 2)

## ข้อมูลผู้จัดทำ
- **รหัสนักศึกษา:** 68030079
- **ชื่อ-นามสกุล:** นายณภัทร รัศมี
- **จำนวนครั้งที่ใช้ AI:** 3 ครั้ง
- **การคำนวณข้อสอบประจำตัว:** รหัสนักศึกษาหลักสุดท้ายคือ `9` นำไปหาร `4` เหลือเศษ `1` บวก `1` = **ข้อที่ 2**

---

## โจทย์ประจำตัว (ข้อที่ 2)
> **ใช้สวิตช์ 2 ตัวควบคุมการเคลื่อนที่และหยุดของ LED**

### เงื่อนไขการทำงาน (Remarks)
1. ใช้ **LED 8 ดวง**
2. **การเคลื่อนที่** หมายถึง วิ่งไปและวิ่งกลับ (จากดวงที่ 1 ไปดวงที่ 8 และวิ่งกลับจากดวงที่ 8 มาดวงที่ 1 ต่อเนื่องกัน)
3. **สวิตช์สามารถกดควบคุมการเคลื่อนที่ได้ทุกขณะ** (เขียนด้วย **ESP-IDF** ใช้ `esp_timer_get_time()` และ FreeRTOS `vTaskDelay(pdMS_TO_TICKS(10))` แบบ Non-blocking ทำให้กดปุ่มตอบสนองได้ทันทีทุกจังหวะ)
4. **สวิตช์ 2 ตัว (+/-)**:
   - **สวิตช์ตัวที่ 1 (`+` / PUSH BT1 - GPIO 32):** กดเพื่อสั่งให้ LED **เคลื่อนที่ (Start / Resume)**
   - **สวิตช์ตัวที่ 2 (`-` / PUSH BT2 - GPIO 33):** กดเพื่อสั่งให้ LED **หยุดเคลื่อนที่ (Stop / Pause)** ณ ตำแหน่งปัจจุบันทันที
